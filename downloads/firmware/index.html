>latest firmware here<

Attention: Calibration of Gyro/Acc/Mag required. Press and Hold both Volume Buttons for 5 seconds after boot to start the calibration wizard.

Firmware update instructions:

  • when turned off, press and hold the power-button and volume-up-button for 5 seconds to enter flashing/bootsel mode.
  • a USB-drive/mass storage device does now appear when plugged into a computer or phone
  • copy your firmware.uf2 file to the RPI-RP2 drive
  • the vario boots with the new firmware once completed
  • unplug the vario

v0.1.3(RC15) download

  • complete rebase on master
  • new: config "takeoff_volume":"Mute|Low|Medium|High|Full"
    • Volume will be set prior Takeoff and "startup_volume" will be restored after landing
  • INS fixes:
    • Now uses bias-corrected acc_body
    • VQF now receives raw measurements, bias correction only for vario
    • Clear formula: bias = IMU - gravity - GNSS_acceleration
    • Timestamp Inconsistencies
    • complete INS reset at high VDOP

v0.1.3(RC14)

  • new: replace vario estimator with INS (Instant Vario) and use of accelerometer and compass
  • Attention: Calibration of Gyro/Acc/Mag required. Press and Hold both Volume Buttons for 5 seconds after boot to start.

v0.1.3(RC13) download

  • fix: implement new wind estimator approach
  • fix: AGL tile selection in western area
  • new: refresh initial AMSL altitude after high accuracy GPS-lock

v0.1.3(RC12) download

  • fix: finalized the display driver (no ghosting, fadeout, smeirs)
  • removed config element: "display_version": 1
  • known issues: wind estimator arrow is 180deg flipped

v0.1.3(RC11) download

  • fix: sporadic hickups after landing before stats screen
  • fix: randomly no config loaded
  • fix: wind estimator pointing wrong at certain heading
  • reduce GPS update rate to 5Hz

v0.1.3(RC10) download

  • new: widget altitude gain, which displays difference to 30sec ago
  • new: configurable Flight Screen (Default/Numbers)
  • new configuration elements:
"flight_layout": "[Default|Numbers]",

v0.1.3(RC9) download

  • rebased on master b8361b2
  • improve config deserialization
  • synchronize-igc-record-ticker
  • fix: changed windspeed algorithm (increased prediction by ~40-
  • new: optional, configurable shutdown screen to show Owner Details
  • new: Temperature based LUT selection to reduce ghosting and washout
  • new: configurable vario thresholds (defaults: 0.2m/s und -2.0m/s)
  • new configuration elements:
"shutdown_information": "<optional text>",
"climb_threshold": 0.2,
"sink_threshold": -2.0,

  • fix: limit IGC handler to write BRecords once per second
