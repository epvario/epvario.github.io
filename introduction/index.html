Introduction

Complete guide to the EPVario open source paragliding variometer

EPVario - Open Source Paragliding Variometer

EPVario is a powerful, open source variometer specifically designed for paragliding pilots. Built with modern embedded systems technology and a focus on reliability, accuracy, and usability.

What is EPVario?

EPVario combines cutting-edge hardware with sophisticated software to provide pilots with precise flight data in real-time. The device weighs just over 80 grams and mounts easily on your risers, delivering critical information through a high-contrast E-paper display that remains readable even in direct sunlight.

Why EPVario?

Open Source & Open Hardware

  • Complete firmware source code available on GitHub
  • PCB design files and schematics freely available
  • 3D printable case designs included
  • Community-driven development and improvements

Advanced Technology

  • RUST Programming Language: Memory-safe, high-performance firmware
  • Embassy Async Framework: Real-time embedded programming with async/await
  • Modern Hardware: RP2040 dual-core microcontroller
  • E-Paper Display: 2.9" WeAct Studio module with excellent visibility

Professional Features

  • Kalman filter altitude estimation with GPS/barometric sensor fusion
  • Advanced wind speed and direction estimation using circle-fitting algorithms
  • VDOP-adaptive GPS filtering for optimal accuracy
  • FAI CIVL approved IGC logging with G-record security
  • Altitude Above Ground Level (AGL) using SRTM elevation data

Key Capabilities

Flight Data

  • Altitude: Precise MSL altitude using sensor fusion
  • Vertical Speed: Real-time climb/sink rate with audio feedback
  • Horizontal Speed: GPS-derived ground speed
  • Glide Ratio: Calculated glide performance
  • Wind Estimation: Speed and direction during thermal flight

Navigation & Safety

  • Compass: Magnetic heading with wind direction overlay
  • AGL Display: Height above terrain for safety awareness
  • Flight Time: Automatic flight detection and timing
  • Battery Monitoring: Real-time voltage and charge level

Data Logging

  • IGC Files: Competition-ready tracklog files
  • Flight Statistics: Post-flight analysis data
  • MicroSD Storage: Local data storage and backup

Hardware Specifications

Core Components

  • MCU: Raspberry Pi RP2040 (dual-core ARM Cortex-M0+)
  • Display: WeAct Studio 2.9" E-Paper (296x128 pixels)
  • GPS: Walksnail WS-M181 (GPS, GLONASS, Galileo, BeiDou)
  • Sensors: BMP280 barometer, LSM6DS3 IMU, QMC5883 compass
  • Audio: 1W 8Ω speaker with MAX98357A amplifier
  • Storage: MicroSD card slot for data logging
  • Power: 1100mAh LiPo battery with USB-C charging

Physical

  • Weight: ~80 grams including battery
  • Size: Compact single-PCB design
  • Case: 3D printable with multiple mounting options
  • Connectivity: USB-C for charging and firmware updates

Software Architecture

Real-Time Operation

The firmware uses Embassy's async framework to manage multiple concurrent tasks:

  • GPS data processing and quality assessment
  • Barometric pressure monitoring and filtering
  • Wind estimation from flight path analysis
  • Display updates with partial refresh optimization
  • Audio feedback generation
  • Data logging to SD card

Advanced Algorithms

  • Kalman Filter: Fuses GPS and barometric data for optimal altitude accuracy
  • Circle Fitting: Analyzes GPS tracks to estimate wind during thermal flight
  • VDOP Adaptation: Adjusts GPS trust based on satellite geometry
  • Thermal Detection: Identifies lift patterns for improved climb rate indication
