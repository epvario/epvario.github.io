Software Features

Software features and algorithms in EPVario explained

EPVario's firmware is built with cutting-edge algorithms and modern embedded programming techniques to deliver professional-grade variometer functionality in a lightweight package.

Core Flight Instruments

Real-Time Variometer

  • Instant Response: <100ms latency from pressure change to audio feedback
  • Sensitivity Control: Adjustable threshold for lift/sink detection
  • Audio Feedback: Multi-tone system with lift/sink indication
  • Visual Display: Large, clear vertical speed numbers
  • Filtering: Smart noise reduction while maintaining responsiveness

Precision Altitude Tracking

  • Sensor Fusion: Advanced Kalman filter combines GPS and barometric data
  • Adaptive Filtering: VDOP-based GPS trust adjustment
  • MSL Accuracy: Mean Sea Level altitude with ±1m typical accuracy
  • QNH Support: Manual pressure setting for airport reference
  • Altitude Graphs: Historical altitude tracking and display

Advanced Wind Estimation

Our sophisticated wind estimation system analyzes your flight path to calculate wind conditions:

Circle-Fitting Algorithm

  • Real-Time Analysis: Processes GPS tracks during thermal flight
  • Statistical Method: Least-squares optimization for accurate results
  • Multi-Sector Sampling: 6 samples per 60° sector for comprehensive data
  • Gradient Descent: Iterative optimization for precise wind vector calculation

Wind Display

  • Speed & Direction: Accurate wind speed (m/s) and direction (°)
  • Visual Compass: Wind arrow overlay on compass display
  • Thermal Optimization: Helps identify wind drift during climbs
  • Historical Data: Wind tracking throughout flight

Navigation & Safety Features

Altitude Above Ground Level (AGL)

  • SRTM Integration: Uses NASA Shuttle Radar Topography Mission data
  • Automatic Tiles: Downloads elevation data as needed
  • Terrain Awareness: Critical for safe flying in mountainous terrain
  • Dynamic Updates: Real-time AGL calculation and display

Digital Compass with Wind Overlay

  • Magnetic Heading: Calibrated compass with 1-2° accuracy
  • Wind Integration: Shows wind direction relative to heading
  • Course Tracking: Visual flight direction indicator
  • Automatic Calibration: Self-calibrating magnetic declination

GPS Quality Monitoring

EPVario implements sophisticated GPS quality assessment:

VDOP-Based Filtering

  • Quality Levels: Excellent (<600mm), Good (<1000mm), Poor (>1000mm)
  • Adaptive Thresholds: Strict requirements during initialization, relaxed during flight
  • Counter System: 50-packet initialization ensures stable GPS lock
  • Real-Time Assessment: Continuous monitoring of satellite geometry

Multi-Constellation Support

  • GPS: US Global Positioning System
  • GLONASS: Russian satellite navigation
  • Galileo: European satellite system
  • BeiDou: Chinese navigation system
  • SBAS: Satellite-Based Augmentation Systems

Flight Data & Analysis

IGC Flight Logging

Professional competition-ready flight recording:

FAI CIVL Compliance

  • G-Record Security: Cryptographic verification of flight data
  • Competition Legal: Meets all requirements for FAI competitions
  • Data Integrity: Tamper-proof flight record format
  • Automatic Logging: No pilot intervention required

-- #### Comprehensive Data

  • 3D Position: GPS coordinates with altitude
  • Time Stamps: Precise UTC timing for each point
  • Pressure Data: Barometric readings for verification
  • Sensor Status: GPS fix quality and satellite count
  • Event Markers: Takeoff, landing, and significant events

Flight Statistics

  • Flight Time: Automatic takeoff/landing detection
  • Maximum Altitude: Highest point reached during flight
  • Total Distance: Ground track distance calculation
  • Average Speed: Flight performance metrics
  • Climb Analysis: Thermal performance statistics

Real-Time Performance Metrics

  • Glide Ratio: Calculated from speed and vertical velocity
  • Horizontal Speed: GPS-derived ground speed with filtering
  • G-Force Monitoring: Acceleration display for flight envelope awareness
  • Battery Status: Continuous power level monitoring

Advanced Algorithms

Kalman Filter Implementation

Our altitude estimation uses a sophisticated 3-state Extended Kalman Filter:

State Vector

  • Altitude: Current height above mean sea level
  • Vertical Velocity: Rate of climb/descent
  • MSL Pressure: Sea level pressure reference

Sensor Fusion

  • GPS Updates: Position measurements with accuracy weighting
  • Barometric Updates: Pressure measurements with temperature compensation
  • Process Model: Physical motion model with noise characteristics
  • VDOP Boosting: Up to 3x gain multiplication for excellent GPS quality

Thermal Detection Intelligence

  • Pattern Recognition: Identifies thermal entry and centering
  • Lift Mapping: Tracks lift strength across thermal diameter
  • Audio Optimization: Enhanced feedback during thermal flight
  • Visual Indicators: Clear lift/sink indication on display

Power Management

  • Task-Based Architecture: Independent power management per subsystem
  • Display Optimization: Partial updates minimize power consumption
  • GPS Power Control: Intelligent duty cycling for battery life
  • Sleep Modes: Automatic power reduction during inactivity

User Interface

Display Layouts

Multiple screen configurations optimized for different flight phases:

Default Layout

  • Large variometer display with altitude
  • Compass and wind information
  • Speed and glide ratio
  • Battery and GPS status

Numbers Layout

  • Maximum-size numeric displays
  • Essential flight data only
  • High-contrast visibility
  • Simplified information hierarchy

Thermal Layout

  • Enhanced variometer sensitivity
  • Wind direction prominence
  • Thermal centering assistance
  • Climb rate optimization

Audio System

  • Multi-Tone Feedback: Different tones for lift, sink, and neutral
  • Volume Control: Adjustable audio levels
  • Frequency Selection: Customizable tone frequencies
  • Smart Muting: Automatic quiet periods during sink

Configuration System

  • JSON Settings: Human-readable configuration files
  • USB Configuration: Easy setup via computer connection
  • Parameter Tuning: Adjustable sensitivity and thresholds
  • Backup/Restore: Configuration file management

Software Architecture

Embassy Async Framework

  • Concurrent Tasks: Independent subsystems running simultaneously
  • Memory Safety: Rust's ownership system prevents common embedded bugs
  • Real-Time Scheduling: Deterministic task execution
  • Signal-Based IPC: Efficient inter-task communication

Task Organization

  • GPS Reader: Hardware interface and data parsing
  • Sensor Management: Barometer, IMU, and compass handling
  • Altitude Estimation: Kalman filter processing
  • Wind Calculation: Circle-fitting algorithm execution
  • Display Rendering: E-paper update management
  • Audio Generation: Variometer tone production
  • Data Logging: File system and IGC recording

Memory Management

  • Static Allocation: No heap fragmentation issues
  • Zero-Copy Buffers: Efficient data transfer between tasks
  • Compile-Time Optimization: Maximum performance through Rust compiler
  • Resource Safety: Guaranteed memory and resource cleanup

EPVario's software represents state-of-the-art embedded programming applied to paragliding instrumentation. The combination of modern algorithms, safety-focused programming, and real-time performance delivers professional-grade capabilities in an accessible, open-source package.
